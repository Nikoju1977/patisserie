# Compagnons Pâtissiers · Reims

Guide single-file (HTML) des maisons pâtissières, chocolatières et biscuitières
rémoises qui forment les apprentis, orienté compagnonnage (Compagnons du Devoir · Reims).

- Aucune dépendance, aucun `fetch()` — `safeStorage` (IndexedDB → localStorage → mémoire).
- Filtres par spécialité, favoris persistants, fiches détaillées, générateur de lettre de motivation.
- Studio Niko Design · Loire-Atlantique.

## Déploiement
Fichier racine `index.html` : compatible GitHub Pages (activer Pages → branch `main` /root)
ou import direct dans Vercel.
